# Security Policy

## Supported Versions

Just the latest is always supported, which also means support is very limited.

However, Security is of utmost importance, therefore if you believe you have found a security vulnerability, please report it responsibly.

### How to Report

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the maintainers with a clear description of the issue, steps to reproduce, and impact. You can reach me via the contact details listed in the [MediaHub](https://github.com/dariopalladino/mediahub) repository.
3. Include as much detail as possible (platform, version, configuration) so I can reproduce and triage quickly.

### What to Expect

- I will do my best to acknowledge your report as soon as possible (typically within 5 to 10 business days).
- I will keep you updated on my assessment and any fix or mitigation.
- I will credit you in our security advisories and release notes (unless you prefer to remain anonymous).

### Scope

I am especially interested in:

- Authentication or authorization bypass (smb:// protocol authentication)
- Data exfiltration or exposure (credentials, messages, user data)
- Remote code execution
- Issues in dependency chain
- Platform-specific issues (macOS, Windows, Linux) that compromise user data or device security

Out-of-scope for this process: general bugs, feature requests, and issues in third-party services this system integrates with.

### Safe Harbor

I support safe harbor for security researchers who report in good faith. I will not pursue legal action or involve law enforcement against you for discovering or reporting vulnerabilities in accordance with this policy.


Thank you for helping keep MediaHub CLI and its users safe.
